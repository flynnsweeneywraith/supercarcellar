# Product imagery

Drop product photos and brand artwork in this folder (GitHub → Add file →
Upload files works fine). Claude will pick them up from here to:

1. Upload to Shopify (product media + landing page image slots)
2. Reference in the listicle landing page

Suggested names (any image format is fine):

- `packaging-hero.jpg` — floating black bag shot, dark background
- `sleeve-coiled.jpg` — coiled sleeve with branded tab, dark background
- `logo.png` — shield + wordmark artwork

⚠ Reminder from the product brief: the AI-generated packaging shot contains a
fake QR code that will not scan. Composite the real QR artwork over it before
it is used anywhere customer-facing.
