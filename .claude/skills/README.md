# Project Skills

Frontend design skills vendored from [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) (MIT, see `LICENSE-taste-skill`). Claude Code auto-discovers them from this directory.

- **taste-skill** (`design-taste-frontend`) — anti-slop frontend skill for landing pages, portfolios, and new UI builds.
- **redesign-skill** (`redesign-existing-projects`) — audits and upgrades existing UIs without breaking functionality.

The upstream repo also ships aesthetic variants (soft, minimalist, brutalist), a brandkit skill, and image-gen/GPT-specific versions — copy any of them from `skills/` in the upstream repo into this directory if needed.
